# Stage 2 Cycle 6 Engineering Pilot Disposition

The engineering pilot executed before Cycle 6 preregistration used NH2 seed 606001 and NH4 seed 606002. It used four NH2 replications in a reduced topology matrix and five NH4 replications in a one-size-per-split subset. Its only purposes were code-path verification, schema verification, and confirmation that the boundary-targeting method generated both failed and non-failed held-out scenarios.

The pilot is excluded from all Cycle 6 candidate selection, model fitting, confidence intervals, robustness blocks, figures, and hypothesis decisions. Pilot files remain under `results/pilots/stage2_cycle6_engineering` for auditability.
